隱私權政策

stock-gmail 是個人自用工具，僅供應用程式擁有者本人使用，不對外開放。

存取的資料

本工具透過 Gmail API 的唯讀權限（gmail.readonly）存取擁有者本人的信箱，只搜尋並讀取券商寄送的成交通知與對帳單。本工具不會寄信、刪信或修改信件。

資料的使用方式

從信件取得的交易紀錄只會寫入擁有者自己的 Google 試算表。資料不會出售，也不會提供給任何第三方，且不用於廣告。

資料的保存

授權權杖只保存在擁有者自己的電腦與主機上，並限制存取權限。本工具不另外保存信件內容。

Google API 使用規範

本工具使用從 Google API 取得的資料時，遵守 Google API Services User Data Policy，包含其中的 Limited Use 規定。

撤銷授權

可隨時到 Google 帳戶的第三方存取權限頁面撤銷本工具的存取權。

聯絡方式

如有疑問，請透過 GitHub 聯絡擁有者。
